# Snes9x RX nightly

Daily builds of [Snes9x RX](https://github.com/niuus/Snes9xRX) from its newest
commit, for [RiftWii's app store](https://github.com/RiftWii/apps). A build
is made only when upstream has changed, and each one is a release with its
own tag and the exact source it was built from.

These are not official releases. Problems with Snes9x RX itself belong
upstream: https://github.com/niuus/Snes9xRX/issues
